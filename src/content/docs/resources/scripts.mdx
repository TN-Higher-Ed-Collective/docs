# Script Library

Our [GitHub organization](https://github.com/TN-Higher-Ed-Collective) hosts shared scripts, configurations, and automation tools contributed by community members.

## Browse by Category

Visit our GitHub repositories to find scripts organized by technology domain:

- **PowerShell Scripts** — General Windows automation
- **Active Directory** — AD management and user provisioning
- **VMware Automation** — vSphere management scripts
- **Network Configs** — Switch and router templates
- **Security Tools** — Scanning and compliance scripts
- **Monitoring Tools** — Grafana dashboards and Prometheus configs

## How to Use Scripts

1. **Read the code** — Understand what it does before running
2. **Check prerequisites** — Verify required modules and permissions
3. **Test first** — Always test in non-production
4. **Modify for your environment** — Update paths, domain names, etc.
5. **Keep attribution** — Maintain author credits
