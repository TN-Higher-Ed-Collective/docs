# Resources

Shared knowledge, tools, and best practices from IT professionals across Tennessee's community colleges and TCATs.

## Best Practices

Proven approaches and recommendations from our community:

- [Active Directory](/resources/best-practices/active-directory/) — AD management, Group Policy, user provisioning
- [VMware & Virtualization](/resources/best-practices/vmware/) — vSphere, ESXi, clustering
- [Networking](/resources/best-practices/networking/) — Switch configs, VLANs, firewalls
- [Storage](/resources/best-practices/storage/) — SAN, NAS, backup solutions
- [Security](/resources/best-practices/security/) — Compliance, patching, incident response

## Script Library

Our [GitHub organization](https://github.com/TN-Higher-Ed-Collective) hosts shared scripts, configurations, and automation tools. Browse, fork, and contribute.

## How to Contribute Resources

Have a best practice guide, script, or tool to share?

1. Write it up in Markdown format
2. Submit a pull request to our docs repository
3. Or share it in the relevant Discord channel for discussion

See our [Contributing Guidelines](/get-started/contributing/) for details.
