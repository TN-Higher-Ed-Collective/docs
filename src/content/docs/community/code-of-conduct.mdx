# Code of Conduct

## Our Pledge

Tennessee Higher Ed Tech Collective is committed to providing a welcoming, professional, and harassment-free experience for everyone, regardless of age, body size, disability, ethnicity, gender identity and expression, level of experience, nationality, personal appearance, race, religion, or sexual identity and orientation.

## Expected Behavior

- **Be Respectful** — Treat all community members with respect and professionalism
- **Be Collaborative** — Share knowledge generously and help others learn
- **Be Professional** — Use welcoming and inclusive language, keep discussions focused
- **Be Supportive** — Welcome newcomers warmly, answer questions patiently

## Unacceptable Behavior

- Harassment, discrimination, or personal attacks
- Trolling, inflammatory comments, or hostile communication
- Spamming, self-promotion, or vendor sales pitches
- Sharing others' private information or institutional vulnerabilities
- Posting credentials, passwords, API keys, or malicious code

## Scope

This Code of Conduct applies to all Discord channels, GitHub repositories, community events, and any space where members represent TN HETC.

## Enforcement

### Reporting Violations

If you experience or witness unacceptable behavior:
- Direct message any steering committee member on Discord
- All reports are treated confidentially

### Enforcement Guidelines

- **Level 1: Correction** — Private warning, clarification of expectations
- **Level 2: Warning** — Formal written warning, temporary restrictions
- **Level 3: Temporary Ban** — 30-90 day removal from all platforms
- **Level 4: Permanent Ban** — Permanent removal (appeal after 12 months)

## Responsibilities

**Steering Committee:** Enforce fairly and consistently, respond promptly, maintain confidentiality.

**Domain Champions:** Model expected behavior, redirect problematic discussions, report violations.

**All Members:** Read and understand the Code of Conduct, report violations, help maintain a welcoming environment.
