# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),

## [1.0.0] - 2026-02-20

### Added

- Initial documentation site using Astro with astro-terminal-docs theme
- Custom Tennessee theme with state colors (#002D65 blue, #CC0000 red)
- Homepage with hero section, features, and quick links
- About section: Mission & Vision, Core Values, Charter, Governance Model
- Get Started section: Joining guide, Discord guide, GitHub guide, Contributing guidelines
- Community section: Code of Conduct, Steering Committee, Member Institutions
- Resources section: Overview, Best Practices (AD, VMware, Networking, Storage, Security), Script Library
- Events section: Monthly Meetups, Quarterly Summits
- GitHub Actions workflow for automatic deployment to GitHub Pages
- Pagefind-powered full-text search
- Dark/light mode toggle with Tennessee theme as default
- Mobile responsive design with sidebar navigation
- GitHub organization at TN-Higher-Ed-Collective
